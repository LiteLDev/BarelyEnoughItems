# Security Policy

## Supported versions

Only the latest release of BEI receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them privately through [GitHub's private vulnerability reporting](https://github.com/LiteLDev/BarelyEnoughItems/security/advisories/new) instead. You should get a response within a week. Once a fix is released, the issue is disclosed.
